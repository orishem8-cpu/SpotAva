# Музыкальный веб-плеер

Статический музыкальный плеер в стиле тёмного интерфейса «три колонки + нижний плеер».
Чистые HTML5, CSS3 и Vanilla JS — без фреймворков и без бэкенда. Подходит для GitHub Pages.

## Структура проекта

```
index.html      — разметка страницы
style.css       — стили
app.js          — логика плеера
tracks.json     — список треков (метаданные)
music/          — MP3-файлы
covers/         — обложки
```

## Как добавить новый трек

1. Положите MP3-файл в папку `music/`, например `music/mysong.mp3`.
2. Положите обложку в папку `covers/`, например `covers/mysong.jpg` (лучше квадратную, 500×500 и больше).
3. Добавьте запись в конец `tracks.json` (не забудьте запятую после предыдущей записи):

```json
{
  "id": 7,
  "title": "Название трека",
  "artist": "Исполнитель",
  "src": "music/mysong.mp3",
  "cover": "covers/mysong.jpg"
}
```

Важно:
- `id` должен быть уникальным числом.
- Пути пишите **без ведущего слэша** (`music/...`, а не `/music/...`), иначе плеер не заработает в подпапке GitHub Pages.
- Если файла обложки нет, плеер покажет цветную заглушку.
- Плейлисты в левой колонке строятся автоматически: «Все треки» и по одному на каждого исполнителя.
- Имена файлов лучше писать латиницей без пробелов. Регистр важен: `Song.mp3` и `song.mp3` — разные файлы.
- Помните об авторских правах: размещайте только ту музыку, на которую у вас есть права.

## Как запустить локально

Из-за ограничений браузера `fetch` не работает при открытии `index.html` двойным кликом (`file://`). Запустите любой локальный сервер в папке проекта:

```bash
python -m http.server 8000
```

и откройте http://localhost:8000.

## Как включить GitHub Pages

1. Создайте репозиторий на GitHub и загрузите в него все файлы проекта (`index.html` должен лежать в корне).
2. Откройте репозиторий → **Settings** → **Pages**.
3. В разделе **Build and deployment** выберите **Source: Deploy from a branch**.
4. В поле **Branch** выберите `main` и папку `/ (root)`, нажмите **Save**.
5. Через 1–2 минуты сайт станет доступен по адресу `https://username.github.io/repo-name/`.

Размер файла на GitHub ограничен 100 МБ, а весь репозиторий лучше держать в пределах нескольких гигабайт.

## Управление

- Клик по карточке трека — воспроизведение; повторный клик — пауза.
- Клик (и перетаскивание) по полосе прогресса — перемотка.
- Клик (и перетаскивание) по полосе громкости — регулировка громкости.
- Пробел — пауза/воспроизведение.
- Кнопки Shuffle и Repeat — перемешивание и повтор (выкл → список → один трек).
- После окончания трека автоматически включается следующий.
